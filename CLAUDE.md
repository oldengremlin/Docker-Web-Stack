# CLAUDE.md

Директиви для роботи в цьому репозиторії. Прочитай також `README.md`.
Цей файл — стислі робочі правила та пам'ять (оновлюй його щоб нічого не
забувати).

## Хто користувач і як з ним говорити

- Припускаємо рівень senior network engineer: маршрутизація, L2/L3,
  netfilter — рідна territory; Linux/Docker — суміжна експертиза, не
  основна. Пояснювати мережеві базові речі не треба, докерівські
  тонкощі — варто.
- **Відповідай українською.** Описуй дії українською.
- OS користувача — Debian GNU/Linux, IDE — NetBeans. Основні мови —
  Java, Kotlin, Perl. Інструменти — grep/sed/awk.
- Стиль: технічний, без зайвої води. Користувач читає уважно й прямо
  вказує на помилки — приймай це нормально, виправляй і йди далі, без
  зайвих вибачень. Сухий гумор доречний.
- Якщо припускаєшся помилки в скрипті/конфізі (як-от невідповідність
  тега й реальної бази образу в `build.sh` раніше) — визнай прямо,
  поясни причину, виправ. Не заминай.

## Мета проєкту (мірило для всіх рішень)

Працюючий web стек із **мінімальним ручним втручанням**.

## Непорушні правила

На кожен домен — своя структура. Не об'єднувати в Nginx. Це пов'язано з
тим, що Let's Encrypt сертифікати не підтримують вілдкард.

пропонуй альтернативу без нової вагомої причини (як це сталось із
